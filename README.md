# 共看交互原型

按 Figma「测试题 / 交互」402 × 874 画板实现的浏览器原型。图片、头像、表情和图标使用设计稿导出的本地素材。

## 使用

当前版本直接在本地预览。在本目录运行 `python3 -m http.server 5193 --directory dist` 后打开 http://localhost:5193。

- 点笔记图片：普通大图预览，右上角可开启共看。
- 点「131条共看」：直接开启共看。首次引导文案沿用设计稿「试试长按留下共看」。
- 点气泡或数字点：打开附近留言列表，按点赞数降序排列。
- 点留言任意位置：用气泡呈现这条留言自己的落点，整行切换为灰底；不添加红色圆点；点赞按钮独立工作，不触发定位。
- 双击逐级放大、滚轮或双指缩放：根据可见范围与屏幕距离重新聚合；放大后可拖动。示例「5」会展开为独立气泡，「103」会逐级拆成小组，再变为单条气泡。最高支持 24 倍；完全相同坐标的真实留言仍保持成组。电脑按 0 可回到全图。
- 长按图片：生成草稿并打开输入半层；点草稿右上角关闭可取消，点「确认」发布。
- 长按自己已发布的气泡：出现设计稿中的红框和右上角红叉。点叉后确认删除，取消则保留留言；删除结果会保存。键盘可聚焦自己的气泡后按 Delete 进入删除状态。
- 动效：笔记中的文字、导航和底栏淡出，原图片整体从原位置平移到预览位置；不改变尺寸或裁切区域，不做展开和图片淡入；评论列表和输入半层以自然缓动拉起、收起，上方图片同步过渡，不回弹。气泡和删除确认框保留轻微弹簧反馈；遵从系统减少动态效果设置。
- 桌面模拟键盘：拼音输入、中文候选词、连续选词、空格选词、删除与长按连删、大小写、英文/数字模式、表情。也可用电脑键盘与系统中文输入法直接输入。
- 手机：优先唤起手机真实系统键盘。实际系统样式取决于设备及系统版本。
- 自己的留言立即显示，刷新和重新进入后仍优先出现。留言与点赞保存在当前浏览器的本地存储中，不跨设备同步。

## 范围与验证

实现设计稿提供的第 1 张图片及相关共看状态；页码 1/4 和笔记总数 131 沿用画稿，另外 3 张图片没有提供素材，未添加虚构图片。第 1 张图包含 20、103、5 三组演示留言。后续列表条目属于原型测试数据。

已在桌面浏览器走通入口、开关、列表整行定位、中文拼音选词、发布与刷新恢复，以及数字点逐级展开、长按自己的气泡、取消删除、确认删除和刷新后保持删除。12 项自动检查覆盖多级聚合与最大倍率单条展示、同点不拆分、可见范围、坐标换算、缩放锚点、排序、仅删除指定的本人留言、拼音候选和连续组词。手机真实键盘和双指手势尚未在实体设备上验收。

`dist/` 是完整静态网站。`model.js` 管理坐标与聚合，`pinyin.js` 提供离线拼音候选，`motion.js` 管理动效。拼音词典的来源和许可见 `dist/THIRD_PARTY_LICENSES.txt`。
